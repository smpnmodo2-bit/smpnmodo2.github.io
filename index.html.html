🎯 Tujuan Pembelajaran

Setelah mempelajari media ini, peserta didik mampu:

  • 🧩Menjelaskan komponen sistem komputer: hardware, software, dan brainware.
  • ⌨️Mengidentifikasi perangkat input, proses, output, memori, dan penyimpanan beserta fungsinya.
  • 🔄Menguraikan alur kerja data: input → proses → output → penyimpanan.
  • 🧠Membedakan RAM dan penyimpanan (HDD/SSD) berdasarkan sifat datanya.
  • 🏆Menyimpulkan peran tiap perangkat keras dalam satu sistem komputer yang utuh.
